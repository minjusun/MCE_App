# BINDER (MCE_App)

Collectibles trading marketplace MVP: portfolio tracking, a marketplace and peer-to-peer trading, starting with Pokémon cards. Expo (React Native) app with a Supabase backend.

- **New here?** Start with [ONBOARDING.md](ONBOARDING.md): setup, commands, environment, workflow.
- **How it works:** [ARCHITECTURE.md](ARCHITECTURE.md).
- **Contributing:** feature branch, then `node .claude/scripts/ship.mjs check`, then a pull request using the template.
